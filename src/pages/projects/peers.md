### What it is

Peers.law is a complex, content-heavy WordPress site built in close collaboration with the client. The bulk of the work was less about flashy features and more about turning a long list of client requirements into a content structure that the client's own team could manage day-to-day without developer help.

### Tech stack

- **WordPress** as the platform
- **Elementor Pro** for page building and layout
- **Advanced Custom Fields (ACF)** for structured content types and reusable field groups

### What it set out to achieve

- Translate a complex set of client requirements into a content model that's simple to reason about
- Give non-technical editors a structure where adding and updating pages doesn't require touching layout or code
- Build something scalable enough to keep working as the client added more content over time

[See the live site](https://peers.law/).
